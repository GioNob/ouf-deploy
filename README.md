# OUF deployment channel

Private repository for the OUF test VPS deployment channel.

## Current scope

The initial workflow checks only that a Linux x86_64 agent labelled `ouf-vps-test` can accept a GitHub job. It does not check out code, request GitHub permissions, read secrets, use sudo, invoke Docker, change configuration or restart OUF.

A push to the channel-check workflow or its request file queues this check. This permits the connected ChatGPT GitHub integration to request another check through a reviewed file update; workflow-dispatch access is not assumed.

## One-time agent registration

Open repository Settings → Actions → Runners → New self-hosted runner. Select Linux/x64 and use the download/verification commands generated by GitHub, in a new directory owned by oufadmin. Register only to this private repository. Keep the temporary registration token out of chat, repository files and logs.

During configuration choose name `ouf-vps-test` and add label `ouf-vps-test`; retain the normal working-folder default. Start with `./run.sh` as oufadmin. The queued connectivity check should complete and emit `OUF_RUNNER_CHANNEL=PASS`. Foreground execution requires that terminal to remain open; service installation is a separate infrastructure step.
