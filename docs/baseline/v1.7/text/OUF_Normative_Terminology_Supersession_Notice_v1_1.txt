2. Supersession rules
Any remaining phrase “Trusted Approval Surface” in older PETs is interpreted as Trusted Approval Workspace when it denotes HUMAN_REQUIRED approval, unless the local historical context explicitly describes the former umbrella label.
Any remaining “Agent Host” wording is historical/deprecated and does not define an OUF runtime component. MCP Server v1.1 is the only OUF MCP capability-boundary deployable; model/agent runtimes are external consumers.
Protected Human Operations never become MCP/OUF capabilities and are not represented by a fourth mcpClass.
New acceptance evidence must use OUF-E2E-### identifiers and the E2E v0.3 mapping for historical references.
This notice has terminology precedence over older narrative text but never over machine-readable contract field semantics.
